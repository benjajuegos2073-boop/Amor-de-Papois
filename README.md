# Te-Amo-Internet
Página web romántica e interactiva creada como un pequeño universo dedicado al amor. Incluye un infinito formado por “Te Amo”, un corazón central con una carta, un corazón candado con reglas, galería de recuerdos, sección de código y música de fondo. Todo con animaciones suaves, diseño oscuro, elegante y responsive, pensado para guardar recuerdos.
